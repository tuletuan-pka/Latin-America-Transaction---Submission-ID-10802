# A Miniaturized Single-Feed Dual-Band Dual-Orthogonally Polarized Antenna for U2V Communication Systems - Data and Design Repository

This repository contains the simulation design files and exported figure data associated with the research paper/project **"A Miniaturized Single-Feed Dual-Band Dual-Orthogonally Polarized Antenna for U2V Communication Systems"**. 

The files provided allow researchers and reviewers to reproduce our simulations, analyze the raw data, and verify the results presented in the publication.

## 📂 Repository Contents

The repository is organized into simulation files (ANSYS Electromagnetics Desktop) and data files corresponding to the figures in the manuscript.

### 🛠️ Simulation & Design Files
These files require **ANSYS Electronics Desktop (AEDT)** (e.g., HFSS) to open and run.
* `Design in Fig. 1 + 2.aedt` - Contains the simulation setups and geometries corresponding to Figures 1 and 2.
* `Design in Fig. 4.aedt` - Contains the simulation setup corresponding to Figure 4.

## 🚀 How to Use

1. **Viewing Data:** The `.csv` and `.txt` files contain tabular data that can be imported into standard data processing and plotting software such as MATLAB, Python (Pandas/Matplotlib), OriginLab, or Microsoft Excel.
2. **Viewing Designs:** To explore the 3D models and simulation configurations, open the `.aedt` files using ANSYS Electronics Desktop.
